This file is the intentional initial push trigger for Cloudflare's first
Git-connected V45 deployment.

**Important:** The repository root `wrangler.toml` belongs to the separate
analytics Worker `ricardo19-deve-github-io`. Do **not** follow an autogenerated
suggestion to replace the root configuration with
`name = "m-portfolio-companion"`; that would risk breaking analytics.

The M companion Worker uses `m-ai/wrangler.jsonc`, which pins
`m-portfolio-companion`, `account_id`, `M_QUOTA` and preserves already
configured Cloudflare variables and secrets with `keep_vars`.

Deployment success must be established separately in Cloudflare Builds and via
`https://m-portfolio-companion.ricardopacheco-pinheiro.workers.dev/health`;
a successful GitHub commit is **not** proof of a successful Worker deploy.
